# Tic-Tac-Toe

A simple two-player Tic-Tac-Toe game built using HTML, CSS, and JavaScript.

## Features

- Two-player gameplay
- Player X and Player O turns
- Automatic winner detection
- Draw detection
- Restart game button
- Simple and responsive interface

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start playing Tic-Tac-Toe.

## How to Play

- Player X starts the game.
- Players take turns clicking an empty cell.
- The first player to get three symbols in a row wins.
- If all cells are filled without a winner, the game is a draw.
- Click the **Restart Game** button to play again.
